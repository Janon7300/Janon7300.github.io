03 / PROCESS

ไม่ได้เริ่มจากเทคโนโลยี
เริ่มจากลำดับการตัดสินใจ

  1. 01Discover

    มองหาจุดที่ข้อมูลขาดช่วง และงานที่นักศึกษาต้องทำซ้ำ

  2. 02Shape

    เปลี่ยนปัญหาเป็น flow ที่สั้นและเข้าใจได้

  3. 03Build

    แยก UI, parser, API และ data ให้พัฒนาได้เป็นส่วน

  4. 04Validate

    ทดสอบข้อมูลจริง ความผิดพลาด และอุปกรณ์หลายขนาด

  5. 05Iterate

    วัดผล ปรับ SEO และเพิ่มฟีเจอร์ตามการใช้งาน

รายละเอียดรายวิชา รีวิวจากผู้เรียน และข้อมูลที่ช่วยตัดสินใจก่อนลงทะเบียน

  • 01Meta + Canonicaltitle, description และ URL ที่ชัดเจนในแต่ละหน้า
  • 02Open Graph + Twitterแชร์ลิงก์แล้วมีข้อมูลและภาพประกอบครบ
  • 03JSON-LDstructured data สำหรับหน้ารายวิชาและรีวิว
  • 04Sitemapsทั้งไฟล์คงที่และ sitemap รายวิชาที่สร้างแบบ dynamic
  • 05Robots + llms.txtบอก crawler ว่าส่วนใดอ่านได้และเนื้อหาคืออะไร
