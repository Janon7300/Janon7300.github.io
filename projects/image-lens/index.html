THE IDEA 01

Text in an image.
A break in the reading flow.

Text embedded in an image cannot be selected like ordinary webpage text. Image Lens brings translation into the page so readers can keep the original in view.

01 · READ IN PLACEOverlay or panel

Read translated text in boxes over the image or in a separate panel. Toggle the original view to compare it with the translation.

02 · KEEP READINGTranslate after scrolling

Start a translation manually, or enable the optional mode that translates when scrolling stops. Turn it off whenever you want.

03 · CHOOSE YOUR AIBring your own provider

Configure a compatible image-capable model through a Chat Completions endpoint, including Gemini or OpenAI. Fetch model names and test with a sample image before reading.

04 · TWO TARGET LANGUAGESThai or English

Choose the language you want to read. Source-language recognition and translation quality depend on the selected model and the image.

PRODUCT FLOW 02

From setup
to reading in context.

  1. 01Load

    Install the desktop extension from source. HTML, CSS, and JavaScript run without a build step.

  2. 02Configure

    Add your API endpoint and key, choose an image-capable model, and test it with the sample image.

  3. 03Enable

    Choose Thai or English, consent to sending images, and open the translator on a webpage.

  4. 04Translate

    The visible webpage screenshot goes directly to the configured AI provider for text recognition and translation.

  5. 05Read

    View the result over the image or in a panel. Switch back to the original whenever needed.

ENGINEERING 03

One reading tool.
Two browser packages.

A dependency-free extension built with standard web technologies, with separate manifests for Chromium and Firefox.

CHROME / EDGEManifest V3

Load the chromium folder using Developer mode and Load unpacked. The current source package requires Chromium 116 or newer.

FIREFOX DESKTOPManifest V2

Load firefox/manifest.json as a Temporary Add-on in Firefox 140 or newer. This source installation needs to be loaded again after restarting Firefox.

DIRECT TO PROVIDER

The entire visible webpage screenshot is sent to the AI service you configure. There is no developer-operated image server or analytics. API keys normally stay in session storage; translation is an online operation using your own provider quota.

CURRENT SCOPE 04

An experimental tool,
with room to improve.

01Model-dependent results

Text recognition, translation, and placement depend on image quality and the chosen model. The extension does not erase original text or reconstruct image backgrounds.

02Source installation

The repository provides desktop source packages. Firefox installation is temporary, and some browser-protected pages cannot run the translator.

03Own API key

Users configure their own provider and model. Test calls and translations can consume quota or incur provider charges.

04Validation so far

The README reports syntax and request/response checks. Translation quality with a live API has not yet been confirmed for this package.
