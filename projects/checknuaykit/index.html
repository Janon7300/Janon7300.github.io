WORKSPACE

Instead of building a website with a single feature, I designed a core system to help students go from "what they're currently lacking" to "what they should enroll in next," and connected the information needed to make decisions into a single experience.

PERFORMANCE 06

Load only what is needed
Send from the nearest point.

Separate the tasks that the browser needs to download, cache data based on its freshness, and use a CDN for images.

01BROWSERReact.lazy
Suspense skeleton
02EDGE CACHE10–30s public data
SWR 120–300s
03FUNCTIONSVercel API
rate limiting
04DATA / MEDIAFirestore
Cloudinary WebP
LAZY

Routes + modals

The main page and large modal are split-loaded with React.lazy, with a fallback that doesn't empty the screen.

CHUNKS

Vite build

Separating React, router, and icon into manual chunks allows for better cache reuse.

MEDIA

Image pipeline

The image is resized, compressed, converted to WebP, and sent via Cloudinary CDN.
