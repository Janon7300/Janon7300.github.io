02 / Engineering case study

PDF ไม่ได้ส่ง “ตาราง”
มาให้พร้อมใช้

Transcript ส่ง text item หลายร้อยชิ้นพร้อมพิกัด str / x / y ระบบจึงต้องประกอบโครงเอกสารกลับขึ้นมาใหม่ ก่อนจะรู้ว่าวิชาไหนอยู่ตรงไหน

01

Read locally

arrayBuffer() อ่าน binary จากเครื่องผู้ใช้โดยไม่ส่งไฟล์ออกไป

02

PDF Worker

แยกงานหนักออกจาก UI thread ด้วย PDF.js Worker ที่โหลดเมื่อใช้งาน

03

Rebuild layout

จัดกลุ่มบรรทัดด้วยพิกัด Y แล้วเรียงข้อความจากซ้ายไปขวาด้วย X

04

Repair Thai

แปลงอักขระเก่าและจัดตำแหน่งสระกับวรรณยุกต์ให้กลับมาอ่านได้

05

Apply rules

ส่งรายวิชาเข้า multi-pass curriculum engine เพื่อจัดหมวดและคำนวณแผน

LOCAL-FIRST

Privacy เป็นส่วนหนึ่งของสถาปัตยกรรม

การเช็กหน่วยกิตทำงานในเบราว์เซอร์ ไฟล์ transcript จึงไม่ถูกอัปโหลดไปเก็บใน backend

A

เก็บ text สองรูปแบบ

layoutText ใช้จับรายวิชาตามบรรทัด ส่วน rawText ใช้หา metadata ที่พิกัดอาจแบ่งจนเสียรูป

B

หน้าเสีย ไม่ทำลายทั้งไฟล์

ข้ามหน้าที่อ่านไม่ได้เป็นรายหน้า และคืน error ที่บอกสาเหตุแทนการทำให้กระบวนการทั้งหมดหยุด

C

โหลดของหนักเมื่อจำเป็น

PDF.js และ Firebase แยกจาก critical path แล้วโหลดด้วย dynamic import เมื่อผู้ใช้เริ่มใช้งาน
