The hard part

PDF หนึ่งหน้า คือชิ้นข้อความหลายร้อยชิ้น

Transcript ไม่ได้ส่งตาราง รายวิชา หรือเกรดมาให้พร้อมใช้ แต่ส่ง text item พร้อมตำแหน่งบนกระดาษ งานจึงเริ่มจากการสร้างโครงเอกสารกลับขึ้นมาใหม่ในเบราว์เซอร์

01
Read locally
file.arrayBuffer() อ่าน binary จากเครื่องผู้ใช้ แล้วส่งเข้า PDF.js Worker ที่โหลดแบบ dynamic
02
Rebuild layout
อ่านข้อความและพิกัด str / x / y จัดกลุ่มบรรทัดด้วยค่า Y tolerance 11px แล้วเรียงจากซ้ายไปขวาด้วยค่า X
03
Repair Thai
แปลงอักขระเก่าช่วง F700–F71F กลับเป็น Unicode และจัดสระกับวรรณยุกต์ที่สลับตำแหน่งให้ถูกต้อง
04
Parse courses
ตรวจว่าเป็น transcript หรือใบลงทะเบียน จับรหัสวิชา หน่วยกิต เกรด GPA และจัดการวิชาเรียนซ้ำโดยเลือกผลที่ผ่านหรือดีกว่า
05
Apply rules
ส่งข้อมูลเข้า multi-pass curriculum engine เพื่อจัดวิชาบังคับ วิชาเลือก วิชาเฉพาะ และวิชาเสรีตามสาขา ปีหลักสูตร และแผนการเรียน
LOCAL
Privacy is an architecture decision.

การเช็กหน่วยกิตอ่านและประมวลผล transcript ในเบราว์เซอร์ ไฟล์ไม่ถูกอัปโหลดไปเก็บใน backend

A

เก็บ text สองรูปแบบ

layoutText ใช้หารายวิชาตามบรรทัด ส่วน rawText ใช้หา metadata อย่างชื่อ รหัสนักศึกษา และ GPA ที่อาจถูกพิกัดแบ่งจนเสียรูป

B

หน้าเสียหนึ่งหน้า ไม่ทำลายทั้งไฟล์

ระบบข้ามหน้าที่อ่านไม่ได้เป็นรายหน้า ตรวจไฟล์ใส่รหัส ไฟล์ไม่มีข้อความ และเอกสารเสีย พร้อมคืน error ที่บอกสาเหตุให้ผู้ใช้ลองใหม่ได้

C

โหลดของหนักเมื่อจำเป็น

PDF.js และ Firebase ถูกแยกออกจาก critical path แล้วโหลดด้วย dynamic import เมื่อผู้ใช้เริ่มใช้งาน ลดภาระการโหลดหน้าแรกโดยไม่ตัดฟีเจอร์
